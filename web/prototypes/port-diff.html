The change

One box per file. Border, sunken fill and a gap between boxes. A file ends where its box ends.
Sticky file header. Status letter, dimmed directory with a bold filename, +/− counts and a 5-cell bar. It stays pinned while you scroll a long file, so you always know which file you're in.
Git's plumbing lines are gone. diff --git, index, --- and +++ are replaced by the header. Renames, mode changes and binary files become a one-line note.
Hunks read as seams. A divider that names the enclosing function, with the line range pushed to the right.
File list. Sticky on wide screens and stacked above the diff on narrow ones. Click to jump. Files marked "Viewed" collapse and are struck through in the list.
Untracked files (git's status lines at the end of the port diff today) get their own box that says their contents aren't shown.
